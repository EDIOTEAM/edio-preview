01 Built for the bench

Built for the repair professional.

SmartClone was designed from the bench outward. It runs on its own — in a service centre with no spare laptop, on a field visit, or on a crowded workshop table.

It covers the jobs that decide whether a board lives: talking to the system, reading and keeping its memory, editing where needed, writing back, and verifying.

— Bench rule

Read first. Keep the read.

The original contents of a board are the only backup that exists.

02 Operating modes

Seven modes. Start from the symptom.

Pick what the TV is doing on your bench. Every mode below ships in firmware 1.0 — coverage grows with updates.

01 / 08

Mode 1 · T-CON division, mapping, mirror

Fix panel division, LVDS mapping and mirror.

Auto-detects SPI flash or I²C EEPROM, then corrects panel division (1↔2), JEIDA/VESA LVDS bit mapping and image mirror. A single byte, written and verified.

  • SPI flash
  • I²C EEPROM
  • Auto-detect

Mode 2 · UART boot diagnostic

Read the boot log live, find where it stops.

Auto-baud serial probe that parses the boot stream and tracks six boot stages on the LCD. Flags boot loops and kernel panics, and recommends the next action.

  • 9,600–921,600 bps
  • Six boot stages
  • Rule-based

Mode 3 · Panel ID copier

Copy the old panel ID onto the replacement.

Reads the source panel ID EEPROM, archives it to SD, then writes it to the replacement chip. Detects address, size, addressing mode and bank count on its own.

  • Sony panels
  • SD archive
  • Verify

Mode 4 · T-CON PMIC programmer

Set panel voltages in millivolts.

Edit VGH, VGL, VCOM, AVDD and other voltage registers across 33 supported PMIC chips — shown in millivolts, with range checks before any write.

  • 33 chips
  • Range-checked
  • mV entry

Mode 5 · IC programmer

Read, write, verify, erase.

General-purpose programming for 24Cxx EEPROMs and 25xx SPI flash, with SD archive and restore.

  • 24C01–24C512
  • 25xx SPI
  • SD restore

Mode 6 · IR mode

Service codes, decode, learn and replay.

Service-mode codes for a range of TV brands, plus receive and decode (NEC, Sony SIRC, Samsung), learn and replay, a brand database and auto-match.

  • NEC
  • Sony SIRC
  • Samsung

Mode 7 · File manager

Browse the SD card, open any .bin.

Browse files, see storage statistics and open any .bin in the on-device hex viewer and 8 × 8 hex editor.

  • FAT32
  • Hex viewer
  • Hex editor

Shared · USB-CDC host link

Drive it from a computer when you want to.

Over USB the tool appears as a virtual COM port, so a PC application can run the same programming operations. One-click firmware updates too.

  • USB 2.0 FS
  • Virtual COM
  • Updates

Questions

Do I need a computer to use SmartClone?

No. All seven modes run on the device itself. The USB-CDC link to a PC is there if you want it, never required.

Which memory chips does it support?

24C01 to 24C512 EEPROMs, with size, addressing mode and banks auto-detected, and 25xx SPI flash identified by JEDEC ID.

How do I update the firmware?

One click over USB, SD card or mass storage.

Does it use AI to diagnose faults today?

Not yet. UART diagnostics are rule-based. AI-assisted suggestions are on the roadmap — we will say so plainly when they ship.

Can I download firmware images?

Firmware images are not public. For firmware or flashing support, message the EDIO team on WhatsApp.
